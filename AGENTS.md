# Project: Full-stack E-commerce (Next.js + Express)

## Working agreement

- Use Node.js + TypeScript everywhere.
- Use ESM modules (type: module). Avoid CommonJS.
- Do not introduce breaking changes without updating docs and tests.
- Follow `docs/web-client-architecture.md` for all `apps/web-client`
  structure, dependency, naming, and Server/Client Component decisions.
